# relay-sim

电力系统继电保护原理虚拟仿真实验静态站。

## 密码保护

本站面向 GitHub Pages 部署，根目录中的 `.html` 文件都是加密后的发布页。访问任意页面时都会先显示密码页，密码正确后由浏览器使用 WebCrypto 在本地完成 AES-GCM 解密。

明文源码保存在本地 `source/` 目录，该目录已在 `.gitignore` 中排除，不会发布到 GitHub Pages，也不会提交到公开仓库。

## 修改内容

1. 修改 `source/` 中的明文 HTML。
2. 使用密码重新生成加密页面：

```bash
PROTECT_PASSWORD='你的访问密码' node scripts/encrypt-pages.mjs
```

3. 提交根目录中更新后的 `.html` 文件和 `assets/`、`scripts/` 目录。

不要把 `source/` 目录或密码文件提交到公开仓库。

## 安全说明

这是纯静态部署下可行的内容加密方案，密码不会写入前端代码，也不会发送到服务器。拿到页面的人只能看到密文；但知道密码的人仍然可以查看、复制或转发解密后的内容。请使用足够长的密码，并通过可信渠道单独发送给使用者。
