给定参数（供整定计算）：线路额定电压 35 kV（短路计算取平均额定电压 37 kV），线路单位阻抗 z1 = 0.4 Ω/km；本线路 L1 = 50 km（QF1 处装保护1），下一级线路 L2 = 80 km（QF2 处装保护2）；系统等值阻抗：最大运行方式 Zs.min = 2 Ω，最小运行方式 Zs.max = 3 Ω。整定系数：Ⅰ段 Krel = 1.25；Ⅱ段 Krel = 1.15（与下一级Ⅰ段配合）；Ⅲ段 Krel = 1.2、自启动系数 Kss = 1.5、返回系数 Kre = 0.85；最大负荷电流用滑块调节。
已知动作时限：下一级保护2的Ⅰ段 tⅠ,2 = 0.05 s、Ⅱ段 tⅡ,2 = 0.55 s、Ⅲ段 tⅢ,2 = 1.5 s，时限级差 Δt = 0.5 s；故保护1的 tⅡ,1 = tⅠ,2 + Δt = 0.55 s，tⅢ,1 = tⅢ,2 + Δt = 2.0 s。保护2Ⅱ段按能覆盖 L2 全线处理；时间均自故障发生起算，动画简化为保护出口与断路器分闸同步。
